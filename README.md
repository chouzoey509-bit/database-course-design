# 校园二手交易管理系统

> 数据库课程设计项目 | Python | Web | 数据库

## 📌 项目简介

校园二手交易管理系统是一个面向校园场景设计的二手物品信息管理系统。

本项目以数据库课程设计为基础，围绕校园二手物品交易场景，对用户、商品、商品分类等数据进行统一管理，并通过前后端交互实现基本的二手物品发布、浏览和管理功能。

项目主要用于数据库课程学习与实践，涵盖数据库需求分析、数据库设计、数据表设计、后端接口开发、前后端交互以及 Git/GitHub 项目管理等内容。

🚀 项目运行

1. 克隆项目
git clone https://github.com/chouzoey509-bit/database-course-design.git

进入项目目录：
cd database-course-design

2.安装项目依赖
建议使用python虚拟环境。
pip install -r requirements.txt

3. 配置数据库
根据项目中的数据库配置文件完成数据库连接配置。

需要根据本地开发环境修改相应的：

* 数据库地址
* 数据库端口
* 数据库名称
* 数据库用户名
* 数据库密码

4. 初始化数据

如果项目需要初始化数据库或测试数据，可以运行：python seed.py

5.启动项目
运行项目入口文件：python main.py

📐 系统设计

本项目在设计过程中主要完成以下工作：

*需求分析：
根据校园二手交易场景分析系统的主要用户和业务需求。

*数据库概念设计：
根据系统业务需求确定主要实体及实体之间的关系，并进行 E-R 模型设计。

*数据库逻辑设计：
将概念模型转换为关系模型，设计系统所需的数据表以及字段。

*数据库实现：
通过 SQL 和后端数据库操作实现数据的增删改查。

*系统功能实现：
通过后端接口连接前端页面和数据库，实现基本业务功能。
